# Code of Conduct

## The short version

Be decent. Discuss code, not people. Assume the other person is trying to make
the thing work, because they almost always are.

## Expected behaviour

- Keep criticism about the change: what it does, what it breaks, what it claims
  that it can't back up.
- Accept that "no" is a legitimate answer to a feature, and that a maintainer
  saying it owes you a reason but not a debate.
- Respect that people contribute in whatever time they have. Nobody here is
  on-call.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, deliberate derailing,
publishing someone's private information, and persistently re-litigating a
settled decision.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any
other space where you're representing this project.

## Enforcement

Report problems to the maintainer through GitHub — either a private
security-advisory style report or direct contact on the profile at
[@e8kor](https://github.com/e8kor). Reports are handled privately.

Responses, in escalating order: a warning, edited or deleted comments, a
temporary interaction block, or a permanent block from the repository. The
maintainer's decision is final; there is no appeals committee on a project this
size.
